# Instructions spécifiques — Web Design Document Tempo

Ce dossier contient uniquement le Web Design Document interactif.

Avant toute modification :

1. Lire `../AGENTS.md`.
2. Lire `../docs/TEMPO_CONTEXT.md`.
3. Inspecter `../Code/`.
4. Inspecter `../Dashboard/`.

Les dossiers `Code/` et `Dashboard/` sont en lecture seule sauf demande
explicite.

Toutes les créations doivent rester dans `Web document/`.

## Sources de vérité

Pour les composants mobiles, les couleurs, les formes émotionnelles
et le dark mode :

- utiliser `../Code/`.

Pour les graphiques, les filtres et la présentation éditoriale des
données :

- utiliser `../Dashboard/`.

## Contenu rédactionnel

Ne pas rédiger les textes définitifs.

Créer uniquement :

- placeholders de titres ;
- placeholders de paragraphes ;
- placeholders de citations ;
- placeholders de chiffres ;
- placeholders d’images ;
- placeholders vidéo.

Le contenu sera ajouté progressivement, page par page.

## Contraintes techniques

Utiliser :

- HTML ;
- CSS ;
- JavaScript vanilla.

Le document doit :

- fonctionner sur GitHub Pages ;
- être responsive ;
- proposer un light mode ;
- proposer un dark mode ;
- respecter `prefers-reduced-motion` ;
- être imprimable en PDF ;
- ne pas modifier les autres livrables.
